# Fitness & Strength LLC Website

A responsive, single-page marketing site for Fitness & Strength LLC, featuring online coaching and private-gym personal-training inquiries.

## Publish with GitHub Pages

1. In this repository, select **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Set branch to **main** and folder to **/(root)**.
5. Select **Save**.
6. GitHub will provide a public URL, typically `https://jacksonandersoncorp-byte.github.io/fitness-and-strength/`.

## Before launch

Update `hello@fitnessandstrength.com` in `index.html` to the email address that should receive new training inquiries. The current form opens the visitor’s email client with their details populated.
